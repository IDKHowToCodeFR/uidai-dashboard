Domain Model & Operational Metrics

Adheres to strict Domain-Driven Design (DDD). Metrics strictly follow telecom and BPO operational standards:

Domain Metric Canonical Definition Mathematical / Logic Model
Service Level (SL %) Percentage of answered calls connected within threshold (≤20s). SL % = (ACD_20s / (Offered - ABAN_10s)) * 100
Weighted Average SL Aggregated volume-weighted percentage across historical intervals. Sum(ACD_20s) / Sum(Net_Offered) * 100
Average Handle Time (AHT) Total time agent spends processing caller (Talk + Hold + Wrap). AHT = (Talk + Hold + ACW) / Total_ACD_Calls
Average Hold Time Average caller hold duration per answered interaction. Avg_Hold = Total_Hold_Time / Total_ACD_Calls
Dynamic Time Bucketing Auto-resampling aggregation according to query interval span. ≤7d: Daily | >31d: Weekly | >90d: Monthly
Lazy Password Upgrading Transparent cryptographic hash migration upon valid login. if pwd_context.needs_update(): rehash()

Architectural Decision Records (ADRs)

ADR 0001 Asynchronous WebSocket Progress Streaming

Context: Uploading 50MB workbooks took 5-15s, which risked timing out synchronous HTTP requests.
Decision: Adopted a dual-channel upload pattern: WebSocket receives progress percentage broadcasts while FastAPI worker runs in BackgroundTasks.
Result: Zero browser freezing, immediate visual feedback.

ADR 0002 Relational Storage with Idempotent Upserts

Context: Files are often re-uploaded with overlapping timestamps.
Decision: Enforce composite unique constraint (company, language, call_timestamp) and apply SQLite/PostgreSQL ON CONFLICT DO UPDATE.
Result: Guaranteed data consistency with zero duplicate records.

ADR 0003 Client Header Forwarding for Compliance Audit

Context: Frontend acts as an internal proxy, which would mask client IPs as 127.0.0.1.
Decision: Forwarded original X-Forwarded-For and User-Agent headers from Dash to FastAPI.
Result: Non-repudiation audit logging for regulatory standards.
